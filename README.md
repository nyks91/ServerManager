# ServerOrganizer

A BetterDiscord plugin for browsing and organizing Discord servers and folders.

## Features

- Browse servers in a workspace or folder library.
- Search servers, create colored folders and move multiple servers together.
- Reorder servers and folders, then review and apply layout changes.
- Manage unread messages, mute and notification preferences.
- Review server names before confirming departure.

## Installation

Download **ServerOrganizer.plugin.js** from [Releases](https://github.com/nyks91/ServerOrganizer/releases), place it in your BetterDiscord plugins folder and enable it. Open the plugin using its server-list button or **Ctrl+Shift+M**.

Folder and order edits remain drafts until you click **Apply**. Mark-read and notification actions take effect immediately. Leaving servers requires confirmation.
